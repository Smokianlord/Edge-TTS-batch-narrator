# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a feature branch.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run the app with `python src/app.py`.
5. Test chapter parsing and both generation modes when relevant.
6. Open a pull request with a concise description of the change.

Please avoid committing generated MP3 files, browser profiles, logs, virtual environments, or private manuscripts.
