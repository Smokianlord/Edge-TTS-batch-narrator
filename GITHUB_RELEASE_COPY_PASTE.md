## Release description

### First public release

Edge TTS batch narrator turns chapter-based Word documents into automatically generated MP3 narration using Microsoft Edge TTS.

**Highlights**

- English (US) Andrew voice by default (`en-US-AndrewMultilingualNeural`)
- 1–5 parallel chapter workers
- Automatic DOCX chapter detection
- Direct Edge TTS generation mode
- Optional Microsoft Edge browser automation mode
- Automatic MP3 naming
- Resume support by skipping completed files
- Automatic retries
- Professional dark Windows desktop UI
- Per-chapter worker/status tracking and overall progress

**Recommended settings:** Direct Edge TTS, 5 workers, Andrew, 1x speed.

Internet access is required for TTS generation. Browser mode requires Microsoft Edge. This is an independent project and is not affiliated with Microsoft or edge-tts.com.
